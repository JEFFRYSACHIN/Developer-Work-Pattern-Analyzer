About This Project

Developer Work Pattern Analyzer is a Machine Learning application that analyzes a developer's GitHub commit history to identify unusual work patterns.


Project Objective

This project collects public GitHub commit history, performs feature engineering, and applies the Isolation Forest algorithm to identify anomalous developer activity.


Technologies Used

Programming Language Python
Framework Flask
Machine Learning Isolation Forest
Data Processing Pandas
API GitHub REST API
Frontend HTML, CSS, JavaScript

Machine Learning Workflow

  1. Collect developer repositories.
  2. Download commit history.
  3. Perform feature engineering.
  4. Train Isolation Forest.
  5. Detect anomalies.
  6. Generate work pattern report.

Features

  • GitHub API Integration
  • Feature Engineering
  • Isolation Forest
  • Anomaly Detection
  • Flask Web Application
  • Interactive Dashboard
